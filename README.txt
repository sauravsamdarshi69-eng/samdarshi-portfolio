HOW TO OPEN IN VS CODE
1. Extract the ZIP file.
2. Open VS Code.
3. Click File > Open Folder.
4. Select the extracted folder: saurav_portfolio_vscode
5. Open index.html.
6. Preview it by right-clicking index.html and choosing "Open with Live Server"
   (install the Live Server extension if needed). Or double-click index.html
   to open it directly in your browser.

EDITING LINKS/TEXT
Open index.html and use Ctrl+F to find the text or URL you want to change.
Your resume, GitHub, LinkedIn, email, and KaushalyaX project links are in it.
